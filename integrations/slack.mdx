## Slack

<Note>
  Slack integration documentation is being prepared and will be added after launch.
</Note>

The Slack integration will deliver real-time notifications to your team's Slack workspace for Run status events, approval requests awaiting action in Nexus, and Sentinel gate failures. Teams will be able to configure which channels receive which event types, scoped to their Synapse project or tenant. Approval notifications will include a direct link back to the Nexus approval queue.
