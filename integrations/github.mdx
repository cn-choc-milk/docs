## GitHub

<Note>
  GitHub integration documentation is being prepared and will be added after launch.
</Note>

The GitHub integration will connect Synapse to your source repositories so that approved Run output — Apex classes, LWC components, metadata packages — is committed to a feature branch and a pull request is opened for team review. Specialists will push directly to a scoped branch; the branch name and commit history will be visible in the Run's audit trail. A credential stored in the vault will control repository access, scoped to the project.
