## Azure DevOps

<Note>
  Azure DevOps integration documentation is being prepared and will be added after launch.
</Note>

The Azure DevOps integration will make Azure Boards work items available as Signals for Blueprint creation, mirroring the Jira Autopilot path for teams that use ADO for delivery tracking. Run outcomes will be written back to the originating work item as comments and status transitions. Pipeline triggers for governed deployment Runs will be available for teams that use Azure Pipelines as their CI/CD surface.
